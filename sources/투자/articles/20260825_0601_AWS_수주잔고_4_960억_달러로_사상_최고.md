# AWS 수주잔고 4,960억 달러로 사상 최고

**수집일**: 2026-08-25

AWS 수주잔고 4,960억 달러로 사상 최고

- 아마존 AWS 고객 수주잔고가 2026년 2분기 4,960억 달러로 사상 최고를 경신. 2018년 1분기 124억 달러에서 출발했고 최근 1년 증가율이 154.4%로 2년 78.0%, 5년 52.2%를 크게 웃도는 가속 구간

- 앤디 재시 CEO는 2026년과 2027년 서버 용량이 이미 모두 팔렸고 2028년 물량도 빠르게 채워지는 중이라고 밝힘. AI 캐펙스 거품 논쟁에 실수요로 답한 셈이라 클라우드와 메모리 밸류체인 전반에 우호적
